# FedRAMP Moderate System Security Plan (SSP) & POA&M Template
## Project Overview
This repository contains a functional, mock System Security Plan (SSP) and an associated Plan of Action and Milestones (POA&M) for a fictional cloud-based logistics platform (**LogiRoute LLC**). The artifacts demonstrate how to document, test, and remediate compliance controls under the **NIST SP 800-53 Rev. 5 (Moderate Baseline)** framework.

### Skills Demonstrated
* **Framework Alignment:** Mapping corporate IT functions to NIST SP 800-53 control families.
* **Audit Readiness:** Structuring system documentation to satisfy external assessor requirements.
* **Risk Remediation:** Identifying system vulnerabilities and tracking them through a formal POA&M lifecycle.

### Repository Structure
* `README.md` - Executive summary and project description.
* `system-security-plan.md` - Documented baseline security controls (AC and AU families).
* `poam-log.md` - Tracking log for non-compliant controls requiring remediation.
